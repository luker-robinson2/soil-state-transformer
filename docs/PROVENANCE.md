# Provenance

Where each part of this repository came from.

## `alphaearth-soc/`
**Source:** a graduate statistics (STAT 5000) course project, April 2026.
**Data:** 100% public — Google DeepMind AlphaEarth Foundations embeddings,
OpenLandMap SOC, MODIS land cover, all pulled via Google Earth Engine.
**Status:** Publishable as-is. No proprietary content.

Copied except: LaTeX build artifacts (`*.aux`, `*.log`, `*.bbl`, `*.blg`,
`.template`), `.chuck/` agent-memory directories, and the empty
`future_work/data/kssl_raw/` placeholder.

## `foundation-model/`
**Origin:** Personal research — the Soil State Transformer (SST). The architecture
and code were written by me; an earlier version lived inside a former employer's
monorepo, so the import here was **scrubbed** of all company-specific
infrastructure and any customer data before being committed. See
[SCRUB_LOG.md](SCRUB_LOG.md) for exactly what was removed.
**Data:** Public only — WoSIS (ISRIC), ERA5 (Copernicus), SoilGrids (ISRIC).
**Status:** Independent personal project. Safe to publish.

Large binaries were excluded at import (re-downloadable / regenerable):
- WoSIS raw zip (435 MB) — re-downloaded via `data/wosis_downloader.py`.
- Processed `*.parquet` (~14 MB) — regenerated by `scripts/prepare_wosis.py`.
- Model checkpoints (`*.pt`) — retrained via `training/pretrain.py`.
- ERA5 `*.nc` samples — re-downloaded via `data/era5_downloader.py`.

The code, notebooks, and public-data result JSON/PNGs were kept.
